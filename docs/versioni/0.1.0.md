Prima versione pubblica di Jarvis, assistente vocale in italiano e in inglese per Windows.

**Installare:** scarica `Jarvis-Setup-0.1.0.exe` qui sotto e aprilo. Windows mostra "PC protetto" perché
l'installatore non è ancora firmato: "Ulteriori informazioni" e poi "Esegui comunque". Si installa per il tuo utente,
senza permessi di amministratore; il primo avvio controlla il PC, ti fa scegliere il cervello e scarica i modelli
(circa 5 GB).

**Cosa serve:** Windows 11 a 64 bit, una scheda NVIDIA con 8 GB, 16 GB di memoria, circa 10 GB di disco, microfono e
casse o cuffie. Per il cervello: l'abbonamento a Claude, una chiave API di Anthropic, oppure OpenCode, gratis e senza
account.

**Cosa esce dal PC:** solo il testo di quello che chiedi verso il cervello che scegli, le ricerche, i download dei
modelli, un controllo al giorno delle versioni nuove e le segnalazioni, solo se le mandi tu. L'audio no. I dettagli
sono nel README e nella prima pagina dell'installatore.

Gli altri file: `Jarvis-0.1.0.bundle` serve agli aggiornamenti (la copia installata è un repository git, così le
modifiche fatte da Jarvis restano), `SHA256SUMS.txt` ha le impronte dei file. Non serve scaricarli.

**Firma del codice:** la firma gratuita è stata chiesta a SignPath Foundation (*Free code signing provided by
SignPath.io, certificate by SignPath Foundation*, quando sarà concessa). L'installatore si costruisce solo su GitHub
Actions dal codice di questo repository: vedi "Firma del codice" nel README.
