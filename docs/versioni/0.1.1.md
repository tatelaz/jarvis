Correzione dell'installazione e messaggi della finestra in inglese.

**Corretto:** su alcuni PC l'installatore della 0.1.0 si fermava con "Non sono riuscito a preparare Python e le
librerie (codice 2)". La causa era la versione di uv (il programma che prepara Python) entrata da sola nella 0.1.0:
dentro l'installatore non riusciva a creare un suo collegamento di cartella. Ora uv è fissato a una versione provata.
Se l'installazione non riesce, l'installatore non propone più "Avvia Jarvis".

**Corretto:** il primo avvio si chiudeva da solo dopo 3 minuti mentre scaricava i modelli: il guardiano che riavvia
Jarvis quando si blocca lo credeva bloccato. Ora durante il primo avvio Jarvis gli dà segni di vita.

**Altro:**
- Con Jarvis in inglese, anche i messaggi della finestra su Gmail, parola d'ordine e segnalazioni sono in inglese.
- Due segnalazioni rimaste in attesa nello stesso secondo non si cancellano più a vicenda.
- Il README c'è anche in inglese.

**Installare:** scarica `Jarvis-Setup-0.1.1.exe` qui sotto e aprilo. Windows mostra "PC protetto" perché
l'installatore non è ancora firmato: "Ulteriori informazioni" e poi "Esegui comunque". Chi ha già Jarvis installato
lo riceve da solo.

**Firma del codice:** la firma gratuita è stata chiesta a SignPath Foundation (*Free code signing provided by
SignPath.io, certificate by SignPath Foundation*, quando sarà concessa). L'installatore si costruisce solo su GitHub
Actions dal codice di questo repository: vedi "Firma del codice" nel README.

Installer fix: on some PCs the 0.1.0 installer stopped with "could not prepare Python and the libraries (code 2)",
because of the version of uv that came into 0.1.0 by itself; uv is now pinned to a tested version, and "Launch
Jarvis" is no longer offered if the installation did not complete. The first start no longer closes by itself after
3 minutes while downloading the models (the guardian thought it was frozen). Window messages about Gmail, the passphrase and
reports now follow Jarvis's language. Download `Jarvis-Setup-0.1.1.exe` below (Windows warns because the installer
is not signed yet: "More info", then "Run anyway"); existing installations update by themselves.

**Code signing policy:** free code signing has been requested from SignPath Foundation (*Free code signing provided
by SignPath.io, certificate by SignPath Foundation*, once granted). The installer is built only on GitHub Actions from
this repository: see "Code signing policy" in the README.
